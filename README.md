# Repository for Beyond Plugins: Beyond Plugins: Automate with Make in Minutes, Not Months

Contains materials for WordCamp Gdynia 2025 talk. Go to [presentation and resource dashboard](https://kybernaut.cz/en/wc-gdynia-2025-beyond-plugins-automate-with-make-in-minutes-not-months/)

Karolína Vyskočilová (karolina@kybernaut.cz) - [kybernaut.cz/en](https://kybernaut.cz/en)

## Contents

The repository serves as a collection of automation examples for [Make.com](https://www.make.com/en/register?pc=karolina) and setup files for learning Make.com integrations.

## Directory Structure

- **`.mcp.json`** - MCP server setup for Make.com integration
- **`scenarios/`** - Pre-built Make.com automation blueprints
  - **`bank_find_order_update_state.json`** - Bank transaction trigger to WooCommerce order search and status update automation
  - **`form-existing-order-check-project-tool.json`** - Form webhook to existing order lookup with custom project tool integration
  - **`form-urgency-slack.json`** - Form data urgency analysis with Slack integration
  - **`google-sheets-new-wc-coupons.json`** - Google Sheets to WooCommerce coupon creation automation
  - **`wp-ai-socials-google-sheet.json`** - WordPress AI social media automation with Google Sheets
